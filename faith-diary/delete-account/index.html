개발자 qhdgk71이 운영하는 묵상일기(Faith Diary) 앱의 계정과 데이터를 삭제하는 방법을 안내합니다.

삭제 요청 방법

  1. 묵상일기에 가입한 이메일 주소로 qhdgk71@gmail.com에 메일을 보내 주세요.
  2. 메일 제목에 [묵상일기] 계정 삭제 요청이라고 적어 주세요.
  3. 본문에 묵상일기에 가입한 이메일 주소를 적어 주세요.
  4. 본인 확인 후 10일 이내에 계정과 데이터를 삭제하고, 완료되면 메일로 알려 드립니다.

계정은 유지하고 작성한 기록만 삭제하고 싶으시면, 같은 방법으로 메일 제목을 [묵상일기] 데이터 삭제 요청으로 보내 주세요.

삭제되는 데이터

  • 계정 정보 (이메일 주소, 계정 식별자 등)
  • 서버에 암호화된 상태로 저장된 모든 묵상, 기도, 신앙 기록

삭제된 데이터는 복구할 수 없습니다.

보관되는 데이터

계정 삭제 후 개발자가 따로 보관하는 개인정보는 없습니다. 다만 광고 표시 과정에서 Google AdMob이 수집한 정보는 Google의 정책에 따라 관리되며, 광고 ID는 안드로이드 기기의 설정 > 개인정보 보호(또는 Google) > 광고 메뉴에서 재설정하거나 삭제할 수 있습니다.
